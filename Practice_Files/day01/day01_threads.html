How this maps to C

ids[i] = i + 1;
pthread_create(&threads[i], NULL, worker, &ids[i]); // start a worker

// The main thread waits here until every worker has returned.
pthread_join(threads[i], NULL);

create: asks the system to start worker concurrently. join: makes the main thread wait for that specific worker to finish. The main thread prints its final message only after all five joins complete.
